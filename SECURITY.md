# Security Policy

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/l0phtx/mailguard/security/advisories/new)
instead of opening a public issue. I aim to reply within 7 days.

MailGuard only sends DNS queries and never connects to mail servers. Reports can
reveal which providers a domain uses, so treat CSV and JSON exports of your own
domains as internal documents.
